保守边界：

- “法院”“医学院”“机院”等歧义词不归一化；医院名称不直接替代临床学院名称。
- “高等研究院”等未在此目录对应关系中确认的历史或机构名称不自动迁移为另一单位。
- 支持“弘毅学堂”“前沿交叉学科研究院”等非“学院”结尾的已登记单位；完整官方名称优先，保留目录里的括号。
- 多个单位同时出现仍视为范围不唯一；不因某个单位有映射就忽略其他学院。
- 普通词或人名职务中的片段不展开，例如“规划设计院”“对外院校”“马院长”“文院士”。

规则表变更后重启进程。旧字段统一继续使用 `--normalize-applicable-units --unit-normalization-dry-run` 预览，再由操作者执行更新；本次没有更新生产数据。
