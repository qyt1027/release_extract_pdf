# 文件级制度图谱实施计划

用户已确认先做文件级图谱。本轮扩展现有文档关系和图谱投影流程，不实施此前办事卡子系统设计。

## 边界

- 文件为节点，明确引用与废止为有证据的边；普通提及单独标记。
- 现有废止审核结果优先，不覆盖、不自动批准、不更改效力。
- 标题/文号无法唯一对应版本时保留未解析节点，不猜测。
- 多跳只表示关联路径，不传播失效结论。
- 无新增依赖、图数据库或模型调用；只读当前结构版本原文。

## 核心接口

`build_document_graph(documents, clauses, abolition_relations)` 为可离线测试的纯函数。

`query_document_graph(policy_id, depth=1, direction='both', limit=100)` 提供当前制度节点的有界邻域，显式返回截断状态。

读取放在独立模块，避免继续扩大共享存储文件；动态读取不新增持久化事实表，后续需要时再根据来源版本增加缓存。
